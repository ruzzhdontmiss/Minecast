# ⚡ MineCast Frontend

> High-performance Next.js 16 Web Application for MineCast — AI-Powered Content Originality Engine & Decentralized Media Platform.

For full project documentation, system architecture, research paper overview, and smart contracts, please see the [**Root README.md**](../README.md).

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 📦 Features
* **Short-form Reels Feed (`/`)**: Full-screen video and photo stream with live AI originality badges (`Legendary`, `Rare`, `Uncommon`), creator tags, and watch-to-earn reward accumulation.
* **Multimodal Upload Engine (`/upload`)**: Drag-and-drop support for both videos (`MP4`, `MOV`, `WEBM`) and photos (`JPG`, `PNG`, `WEBP`) with pre-publish AI verification.
* **Web3 Token Wallet (`/wallet`)**: On-chain MineCoins (MCT) balance display and Polygon Treasury claim hook.
* **Authentication (`/auth`)**: Supabase Auth with Google OAuth, Phone OTP, Email, and 1-Click Instant Demo Creator Login.
